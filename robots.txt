# robots.txt for the TRP portfolio
#
# The Sitemap directive at the bottom is the one thing here that has to be an
# absolute URL; everything else is path-relative and works on any host.
#
# This file previously contained only a TODO comment and no directives at all,
# which meant crawlers got no instructions and, more importantly, had no
# pointer to the sitemap.

User-agent: *
Allow: /

# Nothing here is disallowed on purpose.
#
# privacy.html is deliberately NOT listed. It carries a noindex robots meta
# tag instead, which is the correct tool: Disallow only stops a crawler
# reading the page, and a page that is never read can never be seen to say
# noindex, so a disallowed URL can still end up listed from external links.
# Letting it be crawled and letting the meta tag do the work is what actually
# keeps it out of results.
#
# assets/docs/ is also not disallowed. The front-end resume is linked from
# the About section and should be findable. The digital designer resume sits
# in the same folder unlinked, and a Disallow line naming that path would
# advertise it to anyone who reads this file, which is the opposite of the
# intent.

Sitemap: https://travispeakman.ca/sitemap.xml
